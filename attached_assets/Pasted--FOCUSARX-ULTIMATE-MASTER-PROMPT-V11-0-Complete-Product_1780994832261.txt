## PHASE 9 — FOCUSARX SIGNATURE FEATURE: "FOCUS DNA"

**This is FocusArx's unique identity feature — something no other app has.**

**Concept:** Every user has a living, evolving "Focus DNA" — a visual representation of their unique study pattern that changes over time.

### How it works:

1. **DNA Strand Visualization:** A beautiful animated double-helix that encodes the user's focus data:
   - Helix color = user's dominant session mode
   - Helix density = sessions per week
   - Node brightness = focus score average
   - Rotation speed = current streak momentum
   
2. **DNA Traits:** 6 traits derived from session data:
   - `Deep Focus Gene` — % of sessions > 45 minutes (high = glows purple)
   - `Night Owl Gene` — % of sessions after 9pm (high = glows dark blue)
   - `Early Riser Gene` — % of sessions before 8am (high = glows orange)  
   - `Consistency Gene` — streak stability score (high = glows green)
   - `Intensity Gene` — average focus score (high = glows red)
   - `Explorer Gene` — variety of session modes used (high = glows rainbow)

3. **DNA Report:** Monthly "Focus DNA Analysis" generated by AI:
   - "Your DNA shows you're a Night Intensity Scholar"
   - "Your Deep Focus Gene is evolving — it's 73% active"
   - Personalized insights based on the gene composition

4. **DNA Sharing:** One-click shareable DNA card:
   - Beautiful dark card with animated helix
   - User's "Focus Type" label (e.g., "Deep Night Scholar")
   - 6 gene bars
   - Share to social feed or download

### Implementation:

**Backend:** `GET /api/dna/:userId` — calculate DNA traits from sessions:
```typescript
export async function calculateFocusDNA(userId: string) {
  const sessions = await db.select().from(focusSessions).where(eq(focusSessions.userId, userId));
  
  const totalSessions = sessions.length;
  if (totalSessions === 0) return null;
  
  const deepFocusGene = sessions.filter(s => s.durationMin >= 45).length / totalSessions;
  const nightOwlGene = sessions.filter(s => new Date(s.completedAt).getHours() >= 21).length / totalSessions;
  const earlyRiserGene = sessions.filter(s => new Date(s.completedAt).getHours() <= 8).length / totalSessions;
  const avgFocusScore = sessions.reduce((a, s) => a + (s.focusScore ?? 70), 0) / totalSessions;
  const intensityGene = avgFocusScore / 100;
  
  // Streak consistency: stddev of daily session gaps
  const consistencyGene = calculateConsistencyScore(sessions);
  
  const modesUsed = new Set(sessions.map(s => s.mode)).size;
  const explorerGene = Math.min(modesUsed / 9, 1);
  
  return {
    deepFocusGene: Math.round(deepFocusGene * 100),
    nightOwlGene: Math.round(nightOwlGene * 100),
    earlyRiserGene: Math.round(earlyRiserGene * 100),
    intensityGene: Math.round(intensityGene * 100),
    consistencyGene: Math.round(consistencyGene * 100),
    explorerGene: Math.round(explorerGene * 100),
    focusType: deriveFocusType({ deepFocusGene, nightOwlGene, intensityGene, consistencyGene }),
    totalSessions,
    dominantMode: getMostUsedMode(sessions),
  };
}
```
