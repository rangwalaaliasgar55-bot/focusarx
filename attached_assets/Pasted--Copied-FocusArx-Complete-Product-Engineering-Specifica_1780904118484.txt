# FocusArx — Complete Product Engineering Specification

## Mission

Transform FocusArx into the world's most powerful productivity, accountability, study, and social super-app. Think: Notion × Duolingo × BeReal × Strava, built for students, self-improvers, and high-performers worldwide.

Every feature below must be implemented completely, integrated into the existing architecture, and shipped as production-ready code. No scaffolding. No placeholders. No TODO comments.

## PART 4 — ACCOUNTABILITY SYSTEM

### 4.1 Study Buddy System
- Send / accept buddy requests
- Shared goal wall (both partners contribute goals)
- Shared streak: counts only when both partners complete daily goal
- Weekly buddy report card (AI-generated summary)
- Buddy challenge: bet XP on who hits a goal first
- Buddy nudge: send a "Hey, focus!" push notification
- Buddy session: start a joint study room directly from buddy chat
- Buddy streak protection (one partner can shield the other's streak once per 30 days)

### 4.2 Focus Circles (Accountability Groups)
- Create a Focus Circle (2–8 people)
- Daily check-in feed (text + optional photo proof)
- Streak board for the circle
- Weekly async video/voice check-in (short clip, up to 60s)
- AI weekly progress review: auto-generated summary of each member's week
- Circle XP pool: shared reward when all members hit daily goal
- Miss penalty system (configurable: XP deduction or just a shame flag)

### 4.3 Commitment Contracts
- Set a public or private commitment ("I will study 4 hours/day for 30 days")
- Attach goal + task list to the contract
- Contract signatories (up to 5 witnesses who get updates)
- Daily completion tracker with streak and percentage
- Auto-post to feed when contract completes (with proof stats)
- Contract failure → loses XP + gets a "Incomplete" badge temporarily
- Stake-based contracts (Pro): lock XP that others can "win" if you fail

## PART 5 — PRODUCTIVITY ENGINE

### 5.1 Smart Goals
- Daily, Weekly, Monthly, Quarterly, Annual goals
- Goal types: Habit | Output | Duration | Milestone | Binary
- Goal templates library (JEE syllabus goals, UPSC prelims, Coding DSA, etc.)
- Goal dependencies (Goal B unlocks after Goal A completes)
- Goal progress bar with percentage + expected vs actual pace
- Goal forecasting: "At this pace, you'll finish in X days"
- Subtask breakdown (unlimited depth)
- Assign goals to groups or buddies
- Goal archive with history and stats
- Goal cloning (duplicate a goal for the next week/month)

### 5.2 Task Manager
- Kanban board view (Backlog | Today | In Progress | Done)
- List view with sort/filter (by due date, priority, subject, XP reward)
- Calendar view (drag tasks to reschedule)
- Timeline / Gantt view for multi-day tasks
- Recurring tasks (daily, weekly, custom cadence)
- Priority levels: P0 Urgent | P1 High | P2 Normal | P3 Low
- Subject tags (color-coded)
- XP reward per task (set manually or AI-suggested)
- Time estimate + actual time tracking per task
- Task notes with rich text and file attachments
- Task sharing (send task to buddy or group)
- Bulk task operations (bulk complete, bulk reschedule, bulk tag)

### 5.3 Habit Tracker
- Create custom habits with icon, color, frequency
- Habit streaks with freeze protection (Pro: 2 freezes/month)
- Completion calendar (GitHub-style heatmap per habit)
- Habit stacking suggestions (AI: "Do X right after Y")
- Habit analytics: completion rate, best day of week, best time
- Habit groups: bundle related habits into a "Stack"
- Social habits: share habit completion to feed
- Habit challenges: join community habit challenges (e.g., "21-day reading habit")

### 5.4 Timer & Focus Sessions
- Pomodoro timer (configurable: 25/50/5/10 default, fully adjustable)
- Deep work timer (no breaks, custom duration)
- Flow state mode (timer hidden, session auto-ends after inactivity)
- Ambient sound player: Lo-fi | Rain | Forest | Cafe | Binaural Beats | Silence
- Background-safe timer (continues on phone lock screen / tab switch)
- Session tagging: tag session to a goal or subject
- Session notes: add note at session end
- Focus score per session (based on continuity, no-break rate)
- Daily focus summary: total hours, avg session length, sessions count
- Focus session sharing: auto-generate a "session complete" post

## IMPLEMENTATION REQUIREMENTS

### Code Quality
- 100% TypeScript (strict mode, no any)
- ESLint + Prettier enforced (CI gate)
- Unit tests for all business logic (Jest, >80% coverage)
- E2E tests for critical paths (Playwright)
- Storybook for all UI components

### Backend
- REST API with full OpenAPI spec
- WebSocket server for real-time features (Socket.io or Ably)
- Rate limiting on all endpoints
- Input validation (Zod schemas)
- Row-level security on all database queries
- Redis for sessions, presence, leaderboard caches
- Queue system for notifications, emails, AI calls (BullMQ or equivalent)
- CDN for all media (images, video, audio)
- Database migrations for every schema change
- Soft deletes on all user-generated content

### Security
- JWT with refresh token rotation
- CSRF protection
- XSS sanitisation on all user input
- SQL injection prevention (parameterised queries / ORM)
- File upload validation (type, size, virus scan)
- Secrets in environment variables only (never committed)

### Performance
- Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms
- Infinite scroll with virtual list (no DOM bloat)
- Image lazy loading + WebP conversion
- API response caching (ETags + Cache-Control)
- Optimistic UI updates for all mutations
- Skeleton loading states for all async content
- Code splitting + lazy routes
