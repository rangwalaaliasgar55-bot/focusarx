## 3. Messaging System Security Fix

### Current Problem

Users can currently see and attempt to message users they are not friends with.

This is not the intended behavior.

### Required Behavior

A user should ONLY be able to:

* View conversations with accepted friends
* Start conversations with accepted friends
* Search/select accepted friends when opening DMs

Users should NOT:

* See every registered user
* Message random users
* Create conversations with non-friends

### Required Implementation

When opening DM:

```text
Current User
↓
Fetch accepted friendships
↓
Display ONLY friends
↓
Allow conversation creation only with friends
```

Backend validation:

```js
if (!areFriends(currentUserId, targetUserId)) {
  return 403;
}
```

Never rely only on frontend restrictions.

Enforce this server-side.
