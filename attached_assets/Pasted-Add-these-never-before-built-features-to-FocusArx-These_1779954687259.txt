## FEATURE: ENVIRONMENTAL SOUND INTELLIGENCE
Not just a white noise player — an adaptive soundscape engine:
- 5 base environments: Deep Forest, Tokyo Rain, Space Station, 
  Ancient Library, Underground Lab
- Each environment has 4 layers that independently adjust volume:
  Layer 1: Ambient base (constant)
  Layer 2: Rhythm layer (subtle beat, syncs to session timer pace)
  Layer 3: Trigger sounds (random but contextual — page turn in library, 
  distant thunder in forest)
  Layer 4: Focus intensifier (volume auto-increases slightly in final 
  10 minutes of a session to signal urgency)
- User never manually adjusts layers — the engine handles it
- When the user gets distracted and returns, the soundscape does a 
  "re-entry fade" — gentle swell back to full volume over 8 seconds
- All audio via Web Audio API — no external files needed, 
  procedurally generated tones and rhythms

## FEATURE: CONSEQUENCE ENGINE
Most apps reward focus. This one also has real consequences for breaking it:
- User sets a "Consequence Contract" at the start of each week:
  - Charity mode: if they miss their weekly focus goal, the app 
    generates a reminder to donate a set amount to a cause they 
    chose (honor system — but the commitment is logged and shown)
  - Public shame mode: generates a draft tweet/post saying 
    "I didn't hit my focus goals this week. Back at it Monday." 
    — user can post it or skip, but the prompt appears every time 
    they open the app until Monday
  - Streak freeze: user earns 1 freeze token per 5-day streak — 
    can spend it to protect a streak on a missed day (like Duolingo 
    but the token is visually shown as a rare item in their inventory)
- Show a "Contracts" page where all past consequences and completions 
  are logged — builds accountability history over time

## FEATURE: DEEP WORK REPLAY
After every session, generate a visual "replay" of the session:
- A timeline scrubber showing the full session with annotated moments:
  - When focus was unbroken (green zones)
  - When a distraction was logged (red spike)
  - When the user paused (yellow gap)
  - When they were in peak flow (detected by zero interaction + 
    session continuing — show as gold zone)
- The replay is shareable as a static image (canvas export) — 
  looks like a audio waveform but for focus
- Caption auto-generated by Claude API: "Your best stretch was 
  34 minutes straight. Peak flow hit at minute 18. 
  One distraction at minute 41 — but you came back strong."
- Save all replays to a "Session Archive" page — scrollable 
  history of every session ever completed, each with its replay visual
