=== TOKEN SYSTEM (ARX) ===
Users earn ARX tokens for:
  - Completing a 25-min focus block     → +25 ARX
  - Task completion                     → +10 ARX
  - Daily login streak (day N)          → +N*5 ARX (cap: 50)
  - Badge unlock                        → +50 ARX
  - Leaderboard rank 1/2/3 weekly       → +200/100/50 ARX
Tokens are stored in the DB on the user record (field: arxTokens: Int).
Tokens can be spent in Forge Room on themes, AI credits, and avatar items.
All token mutations go through POST /api/tokens/award or POST /api/tokens/spend.
Token balance always shown in sidebar footer with a progress bar toward next milestone.

=== AUTH & ROLES ===
Roles: "USER" | "ADMIN" | "MODERATOR"  (always uppercase, stored as-is in DB)
Role checks must use: role.toUpperCase() === "ADMIN" — never assume casing.
JWT payload: { userId, email, role, iat, exp }
Protected routes use middleware: requireAuth (any logged-in user), requireAdmin (ADMIN only).
Auth errors must return { success: false, error: string } with correct HTTP status codes:
  401 Unauthorized, 403 Forbidden, 404 Not Found, 422 Validation Error.
