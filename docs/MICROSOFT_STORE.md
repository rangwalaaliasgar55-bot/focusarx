# Microsoft Store Packaging

## Overview

FocusArx can be packaged for the Microsoft Store using a lightweight wrapper approach rather than Electron, since the application is a web app with an existing server-side API.

## Recommended Approach: PWA Builder + MSIX

### Why Not Electron?

FocusArx is a Vite-built SPA with a server-side API. Electron would:
- Double the bundle size (~150MB+ for Chromium)
- Require a separate native build pipeline
- Add complexity for an app that already works in browsers

### Recommended: @pwa-builder/static-site + MSIX

1. **PWABuilder** (https://www.pwabuilder.com) can wrap the FocusArx web app as a Windows app
2. **MSIX packaging** is the Microsoft Store requirement
3. The existing PWA manifest (`public/manifest.json`) and service worker (`public/sw.js`) already provide the foundation

## Architecture

```
FocusArx Web App (hosted on Vercel)
    ↓
PWA Builder Static Site wrapper (TWA-like for Windows)
    ↓
MSIX package
    ↓
Microsoft Store submission
```

## Windows Requirements

- Windows 10 version 1809+ (Build 17763+)
- 64-bit (x64)
- 100MB disk space
- Internet connection (app uses server-side API)

## Build Process

### 1. Ensure PWA Readiness

The app already has:
- ✅ `manifest.json` with icons and metadata
- ✅ Service worker (`sw.js`)
- ✅ HTTPS served
- ✅ Responsive design (320px to desktop)

### 2. Generate MSIX Package

Option A — PWABuilder (recommended):
1. Go to https://www.pwabuilder.com
2. Enter your production URL
3. Click "Package for stores" → "Windows"
4. Download the generated MSIX package

Option B — Manual with @pwa-builder/cli:
```bash
npx @pwa-builder/cli package --platform windows --url https://focusarx.site
```

### 3. App Identity

Register in Microsoft Partner Center:
- **App name**: FocusArx
- **Publisher**: [Your publisher name]
- **Package identity name**: [Generated by Partner Center]
- **Publisher ID**: [Generated by Partner Center]

### 4. Icons

Required icon sizes for MSIX:
- 44x44 (Store listing)
- 50x50 (App listing)
- 150x150 (Start menu)
- 310x310 (Start menu wide)
- 310x150 (Start menu wide tile)

Source PNGs exist in `public/`:
- `icon-192.png`
- `icon-512.png`
- `icon-maskable-512.png`

Scale these up for MSIX requirements using the PWABuilder image generator.

### 5. Code Signing

Microsoft Store requires packages to be signed:
- Get a code signing certificate (from Partner Center or a CA)
- Sign the MSIX: `signtool sign /f certificate.pfx /p password package.msix`

### 6. Submission

1. Create app in [Microsoft Partner Center](https://partner.microsoft.com/dashboard)
2. Upload MSIX package
3. Fill in store listing (description, screenshots, categories)
4. Set pricing (free or paid)
5. Submit for certification
6. Certification typically takes 1-3 business days

## Privacy Requirements

For Store submission:
- Privacy policy URL (exists: `/privacy`)
- The app must disclose data collection (analytics, focus data)
- No personal data sent to third parties without consent
- Cookie consent banner (already implemented)

## Update Mechanism

- **Store updates**: Submit new MSIX package to Partner Center
- **Web updates**: Automatic (deploy to Vercel)
- The wrapper loads the latest web version on each launch

## Known Limitations

1. **Offline**: The app requires internet for API calls. Service worker caches static assets but not dynamic data.
2. **Notifications**: Web push notifications work but require the user to grant permission.
3. **Camera**: The focus camera feature requires camera permission.
4. **Socket.IO**: WebSocket connections may be affected by corporate proxies.

## Certification Notes

The app must pass Microsoft Store certification:
- No crashes on launch
- No misleading metadata
- Privacy policy accessible
- Age rating appropriate
- No access to personal data without disclosure
