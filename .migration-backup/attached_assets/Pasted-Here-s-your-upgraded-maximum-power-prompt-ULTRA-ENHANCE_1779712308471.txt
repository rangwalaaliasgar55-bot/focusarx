2. API DESIGN — RESTful + AI-Augmented Endpoints
Core Endpoints

GET /api/v1/roadmap — full roadmap tree with pagination, depth control (?depth=1|2|full), and field selection
GET /api/v1/roadmap/:subjectSlug — subject + all aspects, sorted, with prerequisite graph
GET /api/v1/roadmap/:subjectSlug/:aspectSlug — single aspect full detail

AI-Powered Search (the crown jewel)

GET /api/v1/search?q=&mode=hybrid|semantic|keyword&filters=... — Hybrid search combining:

PostgreSQL full-text search (tsvector) for keyword precision
pgvector cosine similarity for semantic understanding (via pre-computed embeddings)
BM25 scoring + semantic re-ranking using Reciprocal Rank Fusion (RRF)
Filter support: ?subject=&difficulty=&tags=&isFree=&maxTime=

AI Insight Endpoints

POST /api/v1/ai/explain — send an aspect ID, get an AI-generated plain-English explanation using the Anthropic Claude API
POST /api/v1/ai/prerequisite-check — given a list of known topics, get an AI-generated readiness assessment for a target subject
POST /api/v1/ai/learning-path — given a goal (e.g., "I want to do LLM fine-tuning"), return an AI-generated ordered sequence of aspects from the database
GET /api/v1/ai/daily-concept — returns a random aspect with an AI-generated "concept of the day" explanation

Graph & Analytics

GET /api/v1/graph/prerequisites — return full prerequisite dependency graph as adjacency list (for D3/vis.js rendering)
GET /api/v1/analytics/popular — most-searched topics, most-accessed aspects
